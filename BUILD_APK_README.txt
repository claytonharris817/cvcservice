CITY VENDING SERVICE REPORT - BUILD APK

FASTEST METHOD WITH GITHUB (NO ANDROID STUDIO REQUIRED)

1. Create a free GitHub repository.
2. Upload the entire contents of this project ZIP to that repository.
3. Open the repository's Actions tab.
4. Select "Build City Vending Android APK".
5. Choose "Run workflow".
6. When the build finishes, open the completed workflow run.
7. Download the artifact named "CityVendingServiceReport-APK".
8. Unzip that artifact. Inside is CityVendingServiceReport.apk.
9. Transfer/tap the APK on your Android phone and allow installation from that source if Android asks.

The workflow is already included at:
.github/workflows/build-apk.yml
